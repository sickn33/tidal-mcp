# TIDAL MCP public landscape brief

On September 4, 2026, public web discovery identified twelve distinct competing repositories that
qualified as TIDAL music MCP servers. Their default branches were inspected at recorded commits.

The largest competing explicit tool inventory contained 78 tools. The TIDAL MCP 1.0 publication
candidate exposes 112: 74 reads, 36 exact mutation previews, and 2 approval-token commit tools.

The defensible public claim is:

> The most complete public TIDAL MCP implementation found in the September 4, 2026 review.

The evidence supports breadth, schemas, write controls, and deterministic test coverage. It does
not justify “official,” guarantee permanent leadership, or prove that tool count alone produces
better answers. See [`docs/COMPETITIVE_MATRIX.md`](../../docs/COMPETITIVE_MATRIX.md) for the full
table and limitations.
